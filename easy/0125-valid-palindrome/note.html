LeetCode 125：Valid Palindrome

用左右指標判斷字串在忽略雜訊後是否前後對稱。

Difficulty：Easy Type：String Pattern：Two Pointers Space：O(1)

題目理解

判斷字串是否為回文，但只看英文字母和數字，並且大小寫視為相同。

核心規則：空格、逗號、冒號等非英數字元不是錯誤，而是要被忽略的雜訊。

為什麼是 Two Pointers？

觀察對應策略
回文要比較左右是否對稱一個指標從左邊走，一個從右邊走
遇到非英數字元要忽略指到雜訊的那一邊單獨移動
大小寫不影響答案比較前使用 Character.toLowerCase

步驟流程

  1. 設定 left = 0、right = s.length() - 1。
  2. 如果左邊不是英數字元，left++ 並重新進入下一輪。
  3. 如果右邊不是英數字元，right-- 並重新進入下一輪。
  4. 兩邊都是有效字元時，轉小寫後比較。
  5. 不同就回傳 false；相同就繼續往中間走。
  6. 全部比較完都沒有失敗，回傳 true。

Java 解法

class Solution {
    public boolean isPalindrome(String s) {
        int left = 0;
        int right = s.length() - 1;

        while (left < right) {
            char leftChar = s.charAt(left);
            char rightChar = s.charAt(right);

            if (!Character.isLetterOrDigit(leftChar)) {
                left++;
                continue;
            }

            if (!Character.isLetterOrDigit(rightChar)) {
                right--;
                continue;
            }

            if (Character.toLowerCase(leftChar) != Character.toLowerCase(rightChar)) {
                return false;
            }

            left++;
            right--;
        }

        return true;
    }
}

Liu 這題的卡住點

一開始把「非英數字元」想成不合法，所以想寫 return false。
但本題規則是忽略它們：非英數不是錯，是雜訊。真正會讓答案變 false 的，是左右兩個「有效字元」不同。

核心記憶

Valid Palindrome：左右指標往中間走，遇到雜訊跳過，遇到有效字元才轉小寫後比較。

複習 Checklist

  • 我知道為什麼空格不能直接讓答案變 false。
  • 我知道 Character.isLetterOrDigit 是用來過濾有效字元。
  • 我知道比較前要用 Character.toLowerCase 處理大小寫。
  • 我知道這題可以不用建立新字串，所以空間是 O(1)。
