LeetCode 1：Two Sum

核心：用 HashMap 快速找到另一個需要的數字。

Difficulty：Easy Type：Array Data Structure：HashMap Language：Java

題目理解

給定一個整數陣列 nums 和一個整數 target，找出兩個不同位置的數字，使它們相加等於 target，並回傳這兩個數字的索引。

注意：這題要回傳的是 index，不是數字本身。

題型分析

Array

題目給定陣列，需要從左到右走訪每個元素。

HashMap

需要快速查找 target - nums[i] 是否已經出現過。

HashMap 要存什麼？

HashMap 欄位這題代表的意思
key數字 nums[i]
value該數字所在的索引 i
 
{ 2 -> 0 }

代表數字 2 出現在 index 0。

容易混淆點：map.get(complement) 拿到的不是 complement 這個數字本身，而是 complement 的 index。因為這題的 HashMap 是「數字 → index」。

解題流程

  1. 建立一個 HashMap，記錄「數字 → index」。
  2. 從左到右走訪 nums。
  3. 計算 complement = target - nums[i]。
  4. 檢查 map 裡是否已經有 complement。
  5. 如果有，回傳 [map.get(complement), i]。
  6. 如果沒有，把目前數字放入 map。
記法：先查，再放。這樣可以避免同一個元素配對自己。

Java 程式碼

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];

            if (map.containsKey(complement)) {
                return new int[] { map.get(complement), i };
            }

            map.put(nums[i], i);
        }

        return new int[] {};
    }
}

複雜度分析

項目複雜度原因
時間O(n)只走訪陣列一次，HashMap 查找平均 O(1)
空間O(n)最壞情況下 map 可能存入多個元素

Liu 這題的卡住點

Liu 有注意到 HashMap 應該和 index 有關，這是對的。需要補精準的是：HashMap 不是只記錄 index，而是記錄「數字 → index」。因為查找時要用數字去找 complement。

這次最重要的修正是：map.get(complement) 裡面放的是「要找的數字」，回傳結果才是它的 index；不是用 index 去 get。

複習重點

  • Two Sum 的核心不是相加，而是快速查找另一個需要的數字。
  • HashMap 的 key 放數字，value 放 index。
  • map.get(complement) 會拿到 complement 的 index，不是 complement 的值。
  • 看到「快速判斷某個值是否出現過」，可以考慮 HashMap。
  • 流程要記住：先查 complement，再放入目前數字。
  • 最後回傳的是 [need 的 index, current 的 index]，不是兩個數字本身。
