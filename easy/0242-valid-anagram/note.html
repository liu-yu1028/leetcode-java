LeetCode 242：Valid Anagram

核心：比較兩個字串的字母出現次數。

Difficulty：Easy Type：String Pattern：Counting Data Structure：int[26]

題目理解

判斷兩個字串 s 和 t 是否由相同字母與相同次數組成。順序可以不同。

Anagram 不是回文。回文看順序，Anagram 看字母種類和次數。

核心想法

用一個 int[26] 計算小寫英文字母出現次數：

  • s 的字母：+1
  • t 的字母：-1
  • 最後全部為 0，代表兩邊完全抵銷。
a -> 0
b -> 1
c -> 2
...
z -> 25

字元轉 index

Java 可以用 char - 'a' 把字母轉成 0～25：

運算結果
'a' - 'a'0
'b' - 'a'1
'z' - 'a'25

Java 程式碼

class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) {
            return false;
        }

        int[] count = new int[26];

        for (int i = 0; i < s.length(); i++) {
            count[s.charAt(i) - 'a']++;
            count[t.charAt(i) - 'a']--;
        }

        for (int num : count) {
            if (num != 0) {
                return false;
            }
        }

        return true;
    }
}

HashMap 解法補充

為了和前面練過的 HashMap 連起來，這題也可以用 HashMap<Character, Integer>。

HashMap<Character, Integer> map = new HashMap<>();

map.put(c, map.getOrDefault(c, 0) + 1); // s 的字母 +1
map.put(c, map.getOrDefault(c, 0) - 1); // t 的字母 -1
重點：getOrDefault 只是拿值，不會自動更新 HashMap。要修改次數，一定要用 map.put(...) 存回去。

最後要檢查每一個 value：

for (int count : map.values()) {
    if (count != 0) {
        return false;
    }
}

Liu 這題的卡住點

這題一開始容易把 Anagram 和 Palindrome 混在一起。這次要記住：Anagram 不看正反順序，而是看每個字母的出現次數。另外，count 是陣列，所以要逐格檢查是否為 0。

HashMap 版本則要記住：HashMap<Character, Integer> 代表「字元 → 出現次數」；getOrDefault 只是拿值，真正更新要靠 map.put。

複習重點

  • 長度不同一定不是 Anagram。
  • int[] count = new int[26];
  • s.charAt(i) - 'a' 把字母轉成陣列 index。
  • s 加一，t 減一。
  • 最後每一格都是 0 才回傳 true。
