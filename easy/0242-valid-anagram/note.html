LeetCode 242：Valid Anagram

總覽頁：這題重點是比較兩個字串的字母出現次數。

Difficulty：Easy Type：String Pattern：Counting Java

題目理解

判斷兩個字串 s 和 t 是否由相同字母與相同次數組成。順序可以不同。

Anagram 不是回文。回文看順序，Anagram 看字母種類和次數。

本題解法分頁

同一題如果有不同解法，分開成不同頁面比較好複習。這個總覽頁只保留題目核心與入口。

解法一：int[26] 計數法

適合小寫英文字母固定為 a-z 的情境。空間固定，寫法精簡，是目前 Solution.java 採用的版本。

 解法二：HashMap 計數法

用 HashMap<Character, Integer> 記錄「字元 → 出現次數」，適合銜接前面 HashMap 觀念。

解法比較

解法優點適合情境
int[26]簡潔、固定空間、速度快字元範圍固定為小寫英文
HashMap概念通用、能記錄任意字元次數想練 HashMap 或字元範圍不固定

Liu 這題的卡住點

這題一開始容易把 Anagram 和 Palindrome 混在一起。Anagram 不看正反順序，而是看每個字母的出現次數。

HashMap 版本要記住：getOrDefault 只是拿值，真正更新要靠 map.put。

核心記憶

Valid Anagram：比較每個字母出現次數。次數全部相同才是 anagram。
