解法二：HashMap 計數法

用 HashMap 記錄「字元 → 出現次數」，銜接前面學過的 HashMap 概念。

HashMap 存什麼？

這題的 HashMap 是：

HashMap<Character, Integer> map = new HashMap<>();
位置意義
key字元，例如 'a'
value出現次數，例如 2

核心想法

  • 走訪 s：每個字元次數 +1
  • 走訪 t：每個字元次數 -1
  • 最後所有 value 都是 0，代表完全抵銷。

重要卡點：getOrDefault 不會自動更新

map.getOrDefault(c, 0) + 1; 只是算出新值，不會改變 HashMap。

正確要用 map.put 存回去：

map.put(c, map.getOrDefault(c, 0) + 1);
map.put(c, map.getOrDefault(c, 0) - 1);

Java 程式碼

import java.util.HashMap;

class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) {
            return false;
        }

        HashMap<Character, Integer> map = new HashMap<>();

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            map.put(c, map.getOrDefault(c, 0) + 1);
        }

        for (int i = 0; i < t.length(); i++) {
            char c = t.charAt(i);
            map.put(c, map.getOrDefault(c, 0) - 1);
        }

        for (int count : map.values()) {
            if (count != 0) {
                return false;
            }
        }

        return true;
    }
}

另一個卡點：map.values()

map.values() 是一整個集合，不能寫 map.values() == 0。要用迴圈逐一檢查每個 value。
