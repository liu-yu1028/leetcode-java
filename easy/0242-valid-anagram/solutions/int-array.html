解法一：int[26] 計數法

利用小寫英文字母只有 26 個的特性，用固定陣列記錄次數。

適合情境

當題目限制字串只包含小寫英文字母 a-z 時，int[26] 是很簡潔的解法。

這是目前 Solution.java 使用的主要提交版本。

核心想法

  • s 的字母出現：對應位置 +1
  • t 的字母出現：對應位置 -1
  • 最後全部抵銷成 0，代表兩邊字母次數相同。

字元轉 index

Java 可以用 char - 'a' 把字母轉成 0～25：

運算結果
'a' - 'a'0
'b' - 'a'1
'z' - 'a'25

Java 程式碼

class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) {
            return false;
        }

        int[] count = new int[26];

        for (int i = 0; i < s.length(); i++) {
            count[s.charAt(i) - 'a']++;
            count[t.charAt(i) - 'a']--;
        }

        for (int num : count) {
            if (num != 0) {
                return false;
            }
        }

        return true;
    }
}

複雜度

項目複雜度原因
時間O(n)走訪字串一次，再檢查 26 個位置
空間O(1)陣列長度固定為 26
