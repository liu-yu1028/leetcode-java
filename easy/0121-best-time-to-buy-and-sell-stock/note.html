LeetCode 121：Best Time to Buy and Sell Stock

一邊走陣列，一邊記錄目前最低買入價與最大利潤。

Difficulty：Easy Type：Array Pattern：Greedy One Pass Space：O(1)

題目理解

給定每天的股票價格，只能做一次買賣，且必須先買再賣。目標是找出最大利潤；如果無法獲利，回傳 0。

核心限制：走到某一天時，只能用以前看過的價格當買入價，不能偷看未來。

Java 解法

class Solution {
    public int maxProfit(int[] prices) {
        int minPrice = prices[0];
        int maxProfit = 0;

        for (int price : prices) {
            int profit = price - minPrice;
            maxProfit = Math.max(maxProfit, profit);
            minPrice = Math.min(minPrice, price);
        }

        return maxProfit;
    }
}

Liu 這題的卡住點

要把「價格」和「利潤」分清楚：
minPrice 是目前最低價格；maxProfit 是目前最大利潤。

所以更新最低價格時，要比較 minPrice 和 price，不是比較 profit 和 maxProfit。

核心記憶

Best Time to Buy and Sell Stock：每天假設今天賣出，用目前看過最低價格計算利潤，持續更新最大利潤。

複習 Checklist

  • 我知道買入日必須早於賣出日。
  • 我知道 profit = price - minPrice。
  • 我知道 minPrice 是價格，maxProfit 是利潤。
  • 我知道不能獲利時答案是 0。
