LeetCode 217：Contains Duplicate

核心：用 HashSet 記錄看過的數字，快速判斷是否重複。

Difficulty：Easy Type：Array Data Structure：HashSet Language：Java

題目理解

給定一個整數陣列 nums，如果任一數字出現至少兩次，回傳 true；如果每個數字都只出現一次，回傳 false。

注意：這題只問 有沒有重複，不問重複的位置，所以不用存 index。

題型分析

Array

題目給定陣列，需要走訪每個數字。

HashSet

需要快速判斷目前數字以前是否出現過。

從暴力法到 HashSet

暴力法會固定一個數字，再往後檢查是否有相同數字，因此需要兩層迴圈。

方法時間想法
暴力法O(n²)每個數字都和後面的數字比較
HashSetO(n)用 set 快速查目前數字以前有沒有出現過

HashSet 要存什麼？

資料結構這題代表的意思
HashSet<Integer>已經出現過的數字
 
set = [1, 2, 3]

代表 1、2、3 都已經看過。

容易混淆點：HashSet 只存元素本身，所以是 HashSet<Integer>，不是 HashSet<Integer, Integer>。

解題流程

  1. 建立一個 HashSet<Integer>。
  2. 用 for (int num : nums) 走訪每個數字。
  3. 如果 set.contains(num)，代表以前看過，回傳 true。
  4. 如果沒看過，就用 set.add(num) 記錄目前數字。
  5. 全部走完都沒重複，回傳 false。
記法：看過就 true，沒看過就 add，最後 false。

Java 程式碼

import java.util.HashSet;

class Solution {
    public boolean containsDuplicate(int[] nums) {
        HashSet<Integer> set = new HashSet<>();

        for (int num : nums) {
            if (set.contains(num)) {
                return true;
            }

            set.add(num);
        }

        return false;
    }
}

複雜度分析

項目複雜度原因
時間O(n)只走訪陣列一次，HashSet 查找平均 O(1)
空間O(n)最壞情況下所有數字都不重複，set 會存入 n 個元素

Liu 這題的卡住點

Liu 的解題方向是對的：因為答案只需要 boolean，所以只需要存「出現過的數字」。這次需要補強的是 Java 語法：HashSet<Integer> 只放一個型別，加入元素用 set.add(num)，不是 set.push(num)。

複習重點

  • 題目只問有沒有重複，所以不用 index。
  • HashSet 適合快速判斷某個值是否出現過。
  • set.contains(num)：檢查是否看過。
  • set.add(num)：記錄目前數字。
  • 看到「不需要位置，只需要是否出現」時，可以先想到 HashSet。
